First Conditional

¿Cuando se usa?

Para hablar de situaciones reales o posibles en el futuro.

  • If it rains, I will stay home
  • If you study, you will pass the exam
  • If she calls, I will answer

¿Cómo se forma la estructura?

If + present simple + will + verb base form

Estructura

Forma Estructura
Afirmativa If + subject + present simple, subject + will + verb + complement
Negativa If + subject + present simple, subject + won't + verb + complement
Interrogativa Will + subject + verb + if + present simple + ?

Ejemplos

  • If you work hard, you will get a good job
  • If I have time, I will help you
  • If she doesn't study, she won't pass
