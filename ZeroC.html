Zero Conditional

¿Cuando se usa?

Para hablar de hechos generales, verdades científicas o cosas que siempre son verdad.

  • If you heat water, it boils
  • If you don't eat, you get hungry
  • Plants die if they don't get water

¿Cómo se forma la estructura?

If + present simple + present simple

Estructura

Forma Estructura
Afirmativa If + subject + present simple, subject + present simple
Negativa If + subject + don't / doesn't + verb, subject + don't / doesn't + verb

Ejemplos

  • If you heat ice, it melts
  • If it rains, the ground gets wet
  • If you touch fire, you burn
